# Hibbing Dispensary — Website

Static multi-page website for Hibbing Dispensary (Hibbing, MN). Built with Tailwind CSS (CDN),
Syne / DM Sans / Space Grotesk typography, and the deep-forest-green + gold design system.

## Pages
- `index.html` — Home
- `shop.html` — Shop (Dutchie e-commerce slot, see below)
- `education.html` — Education hub, with articles:
  `cannabis-101.html`, `cannabis-for-beginners.html`, `cannabis-strains.html`,
  `cbd-vs-thc.html`, `benefits-of-cannabis.html`, `cannabis-laws.html`
- `about.html`, `contact.html`
- Legal: `privacy-policy.html`, `terms.html`, `equal-opportunity.html`, `sitemap.html`
- `sitemap.xml`, `robots.txt`

## Replacing the Dutchie placeholder
Open `shop.html` and find the `<!-- DUTCHIE-START -->` / `<!-- DUTCHIE-END -->` markers.
Replace everything between them with your Dutchie embed snippet, e.g.:

```html
<div id="dutchie--embed__script"></div>
<script async src="https://dutchie.com/api/v2/embedded-menu/YOUR-STORE-ID.js"></script>
```

## Editing content
Pages are generated by `build.py` (Python 3, no dependencies beyond `piexif` for image
metadata). Edit content there and run `python3 build.py` to regenerate all pages with a
consistent header/footer — or edit the HTML files directly if you prefer.

Image alt text / EXIF metadata lives in `images/metadata.json` and `embed_metadata.py`.

## Deploying on Cloudflare Pages
1. Cloudflare dashboard → **Workers & Pages → Create → Pages → Connect to Git**
2. Select this repository (`hibbing-dispensary`)
3. Build settings: **Framework preset: None**, **Build command: (leave empty)**,
   **Build output directory: `/`**
4. Deploy. Add your custom domain under the project's **Custom domains** tab.
5. Update `SITE_URL` in `build.py` (and re-run) once the final domain is set, so
   canonical URLs and `sitemap.xml` point at the real domain.
